Privacy policy

Last updated: October 31, 2026

This policy covers the PhonoByte World website and PhonoByte Shorts, the private production tool the owner of the PhonoByte World YouTube channel (@PhonoByteWorld) uses to publish the channel's own videos. PhonoByte Shorts is not offered to the public, and no one else signs in to it.

This website

The website is a static page hosted on GitHub Pages. It has no sign-up, no cookies of its own, no analytics and no ads. GitHub may log visitors' IP addresses for security, as described in GitHub's privacy statement. Fonts are loaded from Google Fonts, video thumbnails from YouTube, the map code (MapLibre) from unpkg.com and the map tiles from OpenFreeMap (or, if it does not answer, VersaTiles), so those services see your IP address when the page loads. Videos open on YouTube, which may store cookies as described in the Google Privacy Policy.

What PhonoByte Shorts accesses

When the channel owner signs in with Google, the tool asks for two YouTube permissions:

  • youtube.upload: to upload and schedule videos to the PhonoByte World channel;
  • youtube.readonly: to read the channel's name and ID, to confirm which channel it is connected to.

It uses these permissions only to upload videos the owner has reviewed and approved, and to show the connected channel. It does not read viewers' data, comments, subscriber lists or any other account's information.

How data is stored

The Google sign-in token is stored only on the owner's own computer, in a file readable only by the owner. It is sent only to Google's servers when the tool talks to the YouTube API. PhonoByte Shorts has no server or database of its own.

Sharing

No data obtained through Google APIs is sold, shared with third parties, or used for advertising. PhonoByte Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Uploading to YouTube is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also disconnects the tool.

Changes

If this policy changes, the new version will be posted on this page with a new date.
